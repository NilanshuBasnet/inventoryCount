# Inventory & Order Tracker
A simple **inventory counting and order management web app** built with HTML, Tailwind CSS, and JavaScript.  
This project helps restaurant staff easily track inventory, adjust counts, and copy the data for orders or reports.

---

## Features

- 📊 **Dynamic inventory counts** with increment/decrement buttons
- 💾 **Auto-save counts** in browser local storage
- ✂️ **Copy inventory data** to clipboard in a clean format
- 🔄 **Reset all counts** with confirmation
- 🖼️ Displays **icons for each inventory item**
- ✅ Supports **decimal values** for precise counting
- ⚡ Mobile-friendly and responsive layout
